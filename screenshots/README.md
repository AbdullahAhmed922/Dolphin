# Project Screenshots

Place your screenshot files in this folder to display them on the main `README.md` file:

- `chat-ui.png` — Screenshot of the main chat interface
- `voice-mode.png` — Screenshot of the WebRTC voice interaction mode
- `vision-mode.png` — Screenshot showing image/vision analysis
- `document-tray.png` — Screenshot showing document attachments/tray

Once added, commit and push:
```bash
git add screenshots/
git commit -m "Add project screenshots"
git push origin main
```
